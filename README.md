# 🧠 Deep Learning Projects

A collection of Deep Learning projects exploring neural network architectures, image classification, transfer learning, sentiment analysis, time-series forecasting, and movie recommendation systems.

## 📌 Projects Overview

### 1. 🌸 Iris Flower Classification
- Classify flower species using a Multilayer Perceptron (MLP).
- Evaluate classification accuracy using sepal and petal features.

### 2. 🔢 Handwritten Digit Recognition
- Recognize handwritten digits from 0–9 using deep neural networks.
- Compare Fully Connected Neural Networks with CNN-based approaches.

### 3. 🖼️ Image Classification with Transfer Learning
- Fine-tune pretrained CNN models such as VGG16 or ResNet.
- Apply transfer learning to classify images into different categories.

### 4. 🎬 Movie Review Sentiment Analysis
- Classify movie reviews as positive or negative using LSTM networks.
- Perform text preprocessing and evaluate model performance.

### 5. 📈 Airline Passenger Forecasting
- Predict future passenger numbers using LSTM models.
- Visualize predictions and compare them with actual values.

### 6. 🍿 Movie Recommendation System
- Predict user movie ratings based on historical preferences.
- Recommend movies using collaborative filtering techniques.

## 🛠️ Tech Stack

- **Language:** Python
- **Deep Learning:** TensorFlow, Keras, PyTorch
- **Data Processing:** NumPy, Pandas
- **Machine Learning:** Scikit-learn
- **Visualization:** Matplotlib

## 🎯 Key Highlights

- Implementation of diverse neural network architectures.
- Hands-on experience with model training and evaluation.
- Exploration of computer vision, NLP, and time-series forecasting.
- Practical applications of deep learning and recommendation systems.

## 🚀 Objective

To develop practical expertise in Deep Learning by implementing neural network models, evaluating their performance, and exploring real-world AI applications.
