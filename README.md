# 🧠 Deep Learning Projects

A collection of Deep Learning projects exploring neural networks, computer vision, natural language processing, time-series forecasting, recommendation systems, and human activity recognition.

## 📌 Projects Overview

### 1. 🌸 Iris Flower Classification
- Classify Iris flowers into Setosa, Versicolor, and Virginica using an MLP.
- Evaluate classification accuracy using sepal and petal features.

### 2. 🔢 Handwritten Digit Recognition
- Recognize handwritten digits (0–9) using deep neural networks.
- Compare fully connected neural networks with CNN-based models.

### 3. 🖼️ Image Classification Using Transfer Learning
- Fine-tune pretrained CNN models such as VGG16 or ResNet.
- Classify images into different categories using transfer learning.

### 4. 🎬 Movie Review Sentiment Analysis
- Classify movie reviews as positive or negative using LSTM networks.
- Apply text preprocessing and evaluate classification performance.

### 5. 📈 Airline Passenger Forecasting
- Predict future passenger numbers using LSTM-based time-series models.
- Visualize predictions and compare them with actual values.

### 6. 🍿 Movie Recommendation System
- Predict user ratings based on historical rating patterns.
- Recommend movies using collaborative filtering techniques.

### 7. 📸 Image Caption Generation
- Extract image features using CNNs and generate captions using RNN/LSTM models.
- Explore the integration of computer vision and natural language processing.

### 8. 📩 SMS Spam Detection
- Classify SMS messages as spam or ham using deep learning models.
- Perform text preprocessing, feature extraction, and message classification.

### 9. 🚶 Human Activity Recognition
- Classify activities such as walking, sitting, standing, and climbing stairs.
- Analyze smartphone accelerometer and gyroscope data using neural networks.

## 🛠️ Tech Stack

- **Programming Language:** Python
- **Deep Learning:** TensorFlow, Keras, PyTorch
- **Data Processing:** NumPy, Pandas
- **Machine Learning:** Scikit-learn
- **Visualization:** Matplotlib
- **Key Techniques:** MLP, CNN, RNN, LSTM, Transfer Learning, Collaborative Filtering

## 🎯 Key Highlights

- Implementation of diverse deep learning architectures.
- Applications in computer vision, NLP, and predictive analytics.
- Model training, performance evaluation, and prediction visualization.
- Exploration of real-world AI and machine learning applications.

## 🚀 Objective

To strengthen practical knowledge of Deep Learning by implementing neural network architectures and applying them to classification, prediction, image understanding, text analysis, and recommendation tasks.
